# GUI Clips Reference
This file serves as a reference for all of the available GUI clip names within the game.

| Name                | Path                           | Description                                                                                                                                                                                                    |
| ------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _uiClose            | _sound/_uiClose.ogg            | The "DUN" sound that plays entering the main menu or character menu.                                                                                                                                           |
| _uiHover            | _sound/_uiHover.ogg            | When hovering over most buttons in the pre-game menus. (Main and multiplayer menu. "Return", "Create Character", and "Selector Character" in the character select menu. "Return" and "Host" in the host menu.) |
| _uiClick01          | _sound/_uiClick01.ogg          | Basic clicking sound. ()                                                                                                                                                                                       |
| _uiClick02          | _sound/_uiClick02.ogg          | Clicking sound for opening menus or accepting. (Main menu's Multiplayer, Settings, and Quit Game buttons. Select Character.)                                                                                   |
| _uiClick03          | _sound/_uiClick03.ogg          | Clicking sound for closing menus or declining. ()                                                                                                                                                              |
| _currencyTally      | _sound/_currencyTally.ogg      | Currency counter goes up, doesn't count for selling items or at 1 million crowns.                                                                                                                              |
| book handled 1      | _sound/book handled 1.ogg      | Quest selected.                                                                                                                                                                                                |
| hampter_login       | _sound/hampter_login.ogg       | Chatbox opened.                                                                                                                                                                                                |
| _triggerMessageTone | _sound/_triggerMessageTone.ogg | Yellow text messages appears during triggers. (Entereing a dungeon room, boss awakens, etc. Different from info yellow text.)                                                                                  |
| ui_errorPrompt      | _sound/ui_errorPrompt.ogg      | Red text appears on top of the screen to indicate "errors" or "failures". (Skill on cooldown, not enough resources, etc.)                                                                                      |
| Name                | Path                           | Description                                                                                                                                                                                                    |
