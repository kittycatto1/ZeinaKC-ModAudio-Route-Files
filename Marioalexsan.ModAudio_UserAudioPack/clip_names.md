# Vanilla Clips Reference
This file serves as a reference for all of the available audio clip names within the game.\
Notes:
- If Volume or Pitch isn't stated, the value is "1.00", except for Music.
- Most Music is played at [V:0.75] unless noted otherwise.
- All Ambience is looped unlike some music, except "sound effect" ambience like time transitions.
- All NPC voxes use [P:0.98-1.07].
- All Character voices are played at [V:0.30] and use "Player Pitch =-0.059" as the range formula. Vanilla limits for the Voice Pitch slider are 0.6-1.25, which should be around [P:0.54-1.30].
