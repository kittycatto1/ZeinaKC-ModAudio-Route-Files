# Homebrewery Clips Reference
This file serves as an example of how Homebrewery audio sources work for modifying them via ModAudio.
- Volumes are configurable in Homebrewery.CFG under **[Sounds]** at [V0.40] by default. You will need to use `relative_replacement_effects : false` to work around this.
